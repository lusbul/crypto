4Шифри в коді

Python · спробуйте самі

Порахуйте сліди — перевірте ключ

Короткий приклад рахує літери й малює текстову гістограму. Другий перебирає 26 ключів для латинського A–Z без пробілів. У практиці українська абетка має 33 літери.

Частоти літер · 5 рядків
from collections import Counter
text = "THE SECRET LETTER IS HERE"
letters = [c for c in text.upper() if c.isalpha()]
for letter, count in Counter(letters).most_common(5):
    print(letter, count, "█" * count)
Перебір ключів · додатковий приклад
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
message = "VHFUHW"
for key in range(26):
    result = ""
    for letter in message:
        result += alphabet[(alphabet.index(letter) - key) % 26]
    print(key, result)
Перевірте себе
  1. Запустіть підрахунок. Які літери потрапили до першої п’ятірки?
  2. Замініть text на власний довший уривок українською, англійською чи німецькою. Порівняйте результати: це частоти саме вашого уривка.
  3. Змініть most_common(5) на most_common(3).
  4. Вставте другий приклад. Знайдіть ключ, який дає SECRET. Чи достатньо лише однієї найчастішої літери, щоб довести правильність ключа?
