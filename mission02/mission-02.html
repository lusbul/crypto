4Шифри в коді

Python · спробуйте самі

Сигнал SOS

Морзе кодує символи крапками й тире. Це кодування, а не шифрування. «?» означає, що символа ще немає у словнику.

Короткий приклад Python
codes = {"S": "...", "O": "---"}
message = "SOS"
result = ""
for letter in message:
    result += codes.get(letter, "?") + " "
print(result.strip())
Перевірте себе
  1. Запустіть SOS: має вийти ... --- ....
  2. Знайдіть код літери A та додайте "A": ".-" у словник. Замініть повідомлення на "SAS".
  3. Доповніть словник іншими літерами та передайте власне слово.

Якщо конструкції Python незнайомі, рекомендуємо ознайомитися з ними. Програмування тут — додатковий спосіб дослідження.

Якщо використовуєте input()
