КРИПТОГРАФІЯ. ПОДОРОЖ У ЧАСІ — СТРУКТУРА КУРСУ

Головна сторінка: index.html
Спільні файли: styles.css, lesson.css, course.js, theme.js.
Спільні ілюстрації: assets/hero.png, assets/waiting.png.

Кожна тема має власну папку mission01 … mission15.
Сторінка теми: mission01/mission-01.html, mission02/mission-02.html тощо.

У mission01 зібрані:
- mission-01.html — матеріали першої теми;
- theme-01-cat.png — ілюстрація;
- theme-01-guide.pdf — урок для завантаження;
- task1.html — наявна сторінка майбутнього завдання;
- image-puzzle.js — збережений скрипт попередньої вправи (не підключений).

У папках mission02 … mission15 — наявні заглушки тем.
Матеріали наступних тем додавайте безпосередньо до відповідної папки.
Посилання на спільні файли з папки місії починаються з ../.
Посилання на матеріал у тій самій папці — лише назва файлу.

Старі theme-01.html … theme-15.html та task1.html залишені як переадресації.
Старі PDF, ілюстрації та допоміжні файли збережені для сумісності.
Шаблон theme.html?theme=8 працює, як раніше.
Відео, PDF і посилання на чат-бот першої теми збережені.

ЗАВАНТАЖЕННЯ НА GITHUB
1. Розпакуйте архів на комп’ютері.
2. Відкрийте репозиторій lusbul/crypto → Add file → Upload files.
3. Перетягніть увесь ВМІСТ розпакованої папки (файли разом з папками).
4. Збережіть через Commit changes.
5. Після оновлення GitHub Pages відкрийте сайт і натисніть Ctrl+F5.
Не видаляйте старі файли: вони зберігають роботу попередніх посилань.
