ВІДЕО
На сторінках першого розділу — «Тут буде відео».
Знайдіть коментар «Замініть # на посилання на відео»,
замініть href="#" на URL і текст кнопки на «Переглянути відео».
Посилання на чат-бот відкривають наявний головний вхід;
сторінка підказує назву потрібного ланцюжка.

Наступні розділи та їхній початковий зміст збережені як заглушки
у mission06 … mission16. До їхнього опрацювання повернемося пізніше.
Спільні файли — у корені, загальні ілюстрації — в assets.
Оригінальні theme-XX.html збережено як переадресації.

ЗАВАНТАЖЕННЯ
Розпакуйте архів. Завантажте весь ВМІСТ у корінь репозиторію crypto
через Add file → Upload files → Commit changes.
Папки мають залишитися папками. Після оновлення натисніть Ctrl+F5.

СХЕМА КОЖНОЇ СТОРІНКИ
1. Відео і матеріали (презентації).
2. Практика (інтерактивні HTML-файли; наприкінці звіт у PDF).
3. Чат-бот (наявний вхід; виберіть названий ланцюжок).
4. Шифри в коді (місце для вашого Python-коду).

ЯК ДОДАТИ PYTHON
У потрібній сторінці знайдіть коментар PYTHON.
Замініть текст усередині <code>...</code> вашим кодом.
Знаки < та & у коді запишіть як &lt; і &amp;.
Це блок для читання коду; запуск Python на сайті поки не додано.

Початкові презентації включені до цього нового комплекту сайту без редагування.
