README.txt на сайт завантажувати необов’язково.

ПРОВЕДЕННЯ
План 40 хв: вхід 3; перестановка 4; частокіл 5; цикли 7; команди 10;
кількість ключів 5; висновок і звіт 3; резерв 3.
Таймер — орієнтир. Тривалість потребує апробації з групою.
Панель «Ведучому» містить маршрут. На етапі 4 організуйте кімнати по 3–4 учасники.
Місцевий командний таймер не є синхронним таймером для різних пристроїв.
Один учасник демонструє ґратку, команда обговорює; кожен записує свій висновок.
Реакції та звіти зберігаються на пристрої учня, не надсилаються викладачу автоматично.
Звіт: Друк → Зберегти як PDF або Завантажити HTML.
Автозбереження — у цьому браузері; якщо воно заблоковане, показується повідомлення.
Після завершення можна повернутися до вправ і переглянути відповіді.
«Далі з підказкою» позначає допомогу у звіті. Власні пояснення оцінює ведучий.

КОНТРОЛЬНІ ОРІЄНТИРИ ДЛЯ ВЕДУЧОГО
1. Картки за номерами: 3,1,5,2,6,4. Кожна позиція використовується рівно один раз.
2. Частокіл: старт унизу, висота 3, зчитування рядками згори вниз.
3. Цикли (1 2 3), (4 5), (6). НСК(3,2,1)=6; зі шифротексту ще 5 застосувань.
4. Наприклад, отвори у клітинках 1,2,5,6 дають коректний трафарет. Є інші правильні відповіді.
5. 4!=24; 6!=720. Для ґраток за фіксованої орієнтації й напряму повороту 4^4=256.
6. Пояснення оцінює ведучий. Велика кількість ключів сама по собі не доводить стійкість.

Без зовнішніх бібліотек, Python Runner та серверних компонентів.
Вправи працюють автономно після завантаження сторінки; після закриття офлайн-доступ
