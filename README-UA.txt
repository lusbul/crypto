ПЕРЕВІРЕНО
AAAAA → BDZGO; HELLOWORLD → ILBDAAMTAZ; зворотне дешифрування; ADU → ADV → AEW → BFX; перемички AB CD; узгоджені результати JavaScript і Python на 100 конфігураціях; повне проходження веббота, відновлення прогресу, завантаження PDF та робота Python у браузері.

Модель: Enigma I/M3, три рухомі ротори з I–V, відбивач B, пряма вхідна абетка A–Z. Кільця і старт — зліва направо. Проводки звірено з https://enigmamuseum.com/rotwirg.htm . Художня ілюстрація не є технічною схемою.
