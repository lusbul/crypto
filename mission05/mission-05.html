Ключове слово керує зсувами

Латинський приклад із презентації: HELP + ONE → VRPD. Використовуйте великі літери A–Z без пробілів, ключ має бути непорожнім. У практиці нижче працюємо з 33 українськими літерами.

Розгорнути короткий приклад
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
text, key = "HELP", "ONE"
result = ""
for i, letter in enumerate(text):
    shift = alphabet.index(key[i % len(key)])
    result += alphabet[(alphabet.index(letter) + shift) % 26]
print(result)
Перевірте себе
  1. Запустіть: має вийти VRPD.
  2. Змініть ключ на "A". Чому текст не змінився?
  3. Змініть + shift на - shift, а текст — на "VRPD". Залиште ключ ONE: ви отримаєте HELP.
  4. Додатково: замініть абетку на українську та % 26 на % len(alphabet). Використайте текст МИР і ключ КОД.

Якщо конструкції Python незнайомі, рекомендуємо ознайомитися з ними. Програмування тут — додатковий спосіб дослідження.
