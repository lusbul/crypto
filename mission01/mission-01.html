Python — помічник мандрівника

Цифрова скитала

Це спрощена таблична модель скитали. Програма записує повідомлення рядками, зчитує його стовпцями й відновлює за тим самим ключем. Ключ моделі — кількість стовпців.

Скопіюйте код у своє середовище Python та запустіть. Можна почати з готового прикладу: самостійно писати програму не потрібно.

print("🏛 Цифрова скитала")

text = input("Введіть повідомлення: ").upper()
key = input("Кількість стовпців — від 2 до 10: ")

if not key.isdigit() or not 2 <= int(key) <= 10:
    print("Потрібне ціле число від 2 до 10.")

elif text == "":
    print("Спочатку введіть повідомлення.")

else:
    columns = int(key)
    rows = (len(text) + columns - 1) // columns

    # Доповнюємо останній рядок крапками
    table = text.ljust(rows * columns, "·")

    print("\n📜 Повідомлення на скиталі:")

    for row in range(rows):
        start = row * columns
        print(table[start:start + columns])

    # Читаємо таблицю стовпцями
    secret = ""

    for column in range(columns):
        for row in range(rows):
            secret += table[row * columns + column]

    print("\n🔒 Секретна стрічка:")
    print(secret)

    # Відновлюємо текст за тим самим ключем
    restored = ""

    for row in range(rows):
        for column in range(columns):
            restored += secret[column * rows + row]

    # Прибираємо лише додані символи
    restored = restored[:len(text)]

    print("\n🔓 Відновлене повідомлення:")
    print(restored)

3. Перевірте себе

Чи збігається відновлений текст із введеним після переведення у великі літери? Чи змінюються самі літери? Навіщо наприкінці додаються крапки?

Якщо якісь конструкції мови Python вам незнайомі, рекомендуємо з ними ознайомитися.

На які конструкції звернути увагу?
input() та print()
Введення даних і виведення результату.
isdigit() та int()
Перевірка запису числа й перетворення рядка на ціле число.
upper(), len() та ljust()
Переведення тексту у великі літери, визначення довжини та доповнення рядка.
if, elif, else
Вибір дій залежно від умови.
for та range()
Повторення дій для рядків і стовпців таблиці.
text[a:b], table[i] та //
Отримання частини рядка, окремого символу й цілої частини результату ділення.
