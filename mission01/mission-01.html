4Шифри в коді

Python · спробуйте самі

Цифрова скітала

Записуємо повідомлення рядками, читаємо стовпчиками. Ключ — кількість стовпчиків. Символ «_» доповнює останній рядок. Використовуйте додатний цілий ключ, наприклад 2, 3 або 4.

Короткий приклад Python
message = "ТАЄМНИЙЛИСТ"
key = 3
while len(message) % key != 0:
    message += "_"
result = ""
for column in range(key):
    result += message[column::key]
print(result)
Перевірте себе
  1. Запустіть код. Для ключа 3 результат — ТМЙСАНЛТЄИИ_.
  2. Змініть ключ на 2 або 4. Як змінюється повідомлення?
  3. Впишіть власне слово великими літерами та зашифруйте його.
  4. Ознайомтеся з len(), циклом while і зрізом [column::key], якщо вони незнайомі.

Якщо конструкції Python незнайомі, рекомендуємо ознайомитися з ними. Програмування тут — додатковий спосіб дослідження.
