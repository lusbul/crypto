Зсуньте абетку — сховайте повідомлення

У цьому короткому прикладі використовуємо 26 великих латинських літер A–Z, як у вашому notebook. У практиці на сайті може бути інша абетка; її довжина визначає кількість зсувів.

Короткий приклад Python
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
message = "SECRET"
key = 3
result = ""
for letter in message:
    if letter in alphabet:
        result += alphabet[(alphabet.index(letter) + key) % 26]
    else:
        result += letter
print(result)
Додатково: знайдіть ключ (ваш notebook)
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

message = "VHFUHW"

for key in range(1, 26):
    result = ""

    for letter in message:
        old_index = alphabet.index(letter)
        new_index = (old_index - key) % 26
        result += alphabet[new_index]

    print("Ключ:", key, "→", result)
Перевірте себе
  1. Запустіть: SECRET із ключем 3 перетвориться на VHFUHW.
  2. Змініть ключ на 1, потім на 5. Порівняйте результати.
  3. Розшифруйте: вкажіть message = "VHFUHW" і key = -3.
  4. У додатковому прикладі переберіть ключі. Який рядок містить зрозуміле слово?
