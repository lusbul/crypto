КОРОТКА СТОРІНКА ПЕРШОЇ ТЕМИ

1. У головній папці репозиторію GitHub замініть theme-01.html і lesson.css.
2. Додайте task1.html — окрему сторінку для майбутнього завдання.
3. Картинка assets/theme-01-cat.png і PDF assets/theme-01-guide.pdf залишаються ті самі.
4. image-puzzle.js для цієї сторінки більше не потрібен.
5. Відео, документ і чат-бот відкриваються кнопками; завдання веде на task1.html.

Для локального перегляду скопіюйте файли в попередню папку сайту. styles.css має залишатися на місці.
