ПЕРША ТЕМА: ВІЗУАЛЬНА ЗАГАДКА

1. Розпакуйте архів.
2. У головній папці репозиторію GitHub замініть theme-01.html і lesson.css, додайте image-puzzle.js.
3. У папці assets замініть theme-01-cat.png.
4. PDF-конспект не змінено. theme-01-guide.pdf у комплекті залишений для зручності.
5. styles.css залишається на місці.
6. Посилання на відео, щоденник і чат-бот збережено.

Загадка: вибрати предмети, що представляють способи передавання повідомлень на відстань. Для перевірки потрібен JavaScript.
