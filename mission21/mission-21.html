Абетка навпаки

Короткий Атбаш для 33 великих українських літер. Зріз [::-1] розвертає абетку, а index() знаходить позицію літери.

Короткий приклад Python
alphabet = "АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ"
message = "КІТ"
result = ""
for letter in message:
    if letter in alphabet:
        result += alphabet[::-1][alphabet.index(letter)]
    else:
        result += letter
print(result)
Перевірте себе
  1. Запустіть код і скопіюйте зашифроване слово.
  2. Вставте результат замість КІТ та запустіть знову. Чому повернувся початковий текст?
  3. Спробуйте КІТ 2026!. Що сталося з пробілами, цифрами та знаком оклику?
