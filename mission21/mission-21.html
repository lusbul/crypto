Атбаш українською

Перша літера абетки замінюється останньою, друга — передостанньою: А ↔ Я, Б ↔ Ю. Застосуйте це саме правило ще раз, щоб відновити повідомлення.

Це навчальна адаптація Атбашу для української абетки з 33 літер. Пробіли, цифри та розділові знаки зберігаються; літери переводяться у великі.

print("🪞 Атбаш: дзеркальна абетка")

alphabet = "АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ"
mirror = alphabet[::-1]

print("\nЗвичайна абетка:", alphabet)
print("Дзеркальна абетка:", mirror)


def atbash(text):
    result = ""

    for symbol in text.upper():
        if symbol in alphabet:
            position = alphabet.index(symbol)
            result += mirror[position]
        else:
            # Пробіли, цифри й розділові знаки зберігаємо
            result += symbol

    return result


message = input("\nВведіть повідомлення українською: ")
secret = atbash(message)
restored = atbash(secret)

print("\n🔒 Зашифроване повідомлення:")
print(secret)

print("\n🔓 Застосували Атбаш іще раз:")
print(restored)
